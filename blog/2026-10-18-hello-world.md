Welcome to my site. I'm Younies, a software engineer on the Internationalization
team at Google in Zürich.

I'll use this blog to write about what I work on and what I learn along the way:
measurement units, grammatical inflection, number and currency formatting,
Unicode CLDR, ICU, ICU4X, and Rust.

The [talks](../talks/) section has the slides from my talks. Every example on my
slides comes from code that runs, and I publish that code next to the slides, so
you can run it yourself.
