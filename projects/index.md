## Open source

:::: cards
::: card
### [ICU4X](https://github.com/unicode-org/icu4x)

Internationalization components in Rust, built for client-side and
resource-constrained environments. I work on measurement units and unit
conversion, and on currency, unit, and duration formatting.

[My pull requests →](https://github.com/unicode-org/icu4x/pulls?q=author%3Ayounies){.more}
:::

::: card
### [ICU](https://github.com/unicode-org/icu)

The ICU4C (C++) and ICU4J (Java) libraries. I work on unit identifiers,
conversion, and formatting, and on grammatical inflection.

[My pull requests →](https://github.com/unicode-org/icu/pulls?q=author%3Ayounies){.more}
:::

::: card
### [Unicode CLDR](https://github.com/unicode-org/cldr)

The locale data behind ICU and many other libraries. I work on UTS #35
specification fixes, unit and currency data, and conformance tests.

[My pull requests →](https://github.com/unicode-org/cldr/pulls?q=author%3Ayounies){.more}
:::

::: card
### [ECMA-402](https://github.com/tc39/ecma402)

Internationalization in JavaScript. I contributed to the
[Intl.DurationFormat](https://github.com/tc39/proposal-intl-duration-format) and
[Smart Unit Preferences](https://github.com/tc39/proposal-smart-unit-preferences)
proposals.
:::
::::
